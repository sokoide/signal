=== Timer ISR vs POSIX Signal Handler ===
This program demonstrates the structural correspondence
between hardware interrupts / ISRs and POSIX signals / handlers.

Hardware interrupt:   IRQ -> CPU saves regs -> IDT -> ISR -> iret
POSIX signal:         setitimer -> kernel saves ucontext_t -> sigaction table -> handler -> sigreturn

A busy CPU loop runs.  Every 500 ms of virtual CPU time,
SIGVTALRM fires and the handler prints the saved PC/SP/FP.
